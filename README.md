# Менеджер служб Windows

Flutter-приложение для Windows, которое позволяет запускать и останавливать службы:

- Управление выбранными пользователем Windows-службами

## Возможности

- Автоматическое обновление статуса служб (каждые 5 секунд)
- Выбор любых установленных Windows-служб из списка с поиском
- Сохранение выбранного набора служб между запусками
- Запуск приложения автоматически при старте Windows
- Кнопки «Запустить» / «Остановить» для каждой службы
- Кнопки «Запустить все» / «Остановить все» с учётом зависимостей: при запуске сначала стартует MSSQL, при остановке — сначала 1С
- Переключение между светлой и тёмной темой с сохранением выбора
- Проверка прав администратора и перезапуск приложения от имени администратора (UAC)
- Системный трей: иконка с контекстным меню, управление службами прямо из трея
- Закрытие окна (крестик, Alt+F4) сворачивает приложение в трей, а не завершает его

## Системный трей

- **Иконка** появляется в области уведомлений сразу после запуска приложения.
- **Левый клик** по иконке — показать/развернуть главное окно.
- **Правый клик** — контекстное меню:
  - статусы служб (информационные пункты);
  - «Запустить: <служба>» / «Остановить: <служба>» для каждой службы;
  - «Запустить все службы» / «Остановить все службы» (с учётом зависимостей);
  - «Открыть окно»;
  - «Выход» — полное завершение приложения (убирает иконку из трея).
- Меню автоматически обновляется при изменении статусов служб (перестраивается только при изменении состояния).
- Если действие из трея не удалось (например, нет прав администратора) — откроется окно приложения с сообщением об ошибке.
- Кнопка в AppBar «Свернуть в трей» скрывает окно, оставляя приложение работать в фоне.
- Кнопка в AppBar «Выйти» полностью завершает приложение: убирает иконку из трея и закрывает окно.

## Выбор служб

При первом запуске список служб пуст. Кнопка с иконкой списка в верхней панели
открывает перечень установленных
Windows-служб. В нём можно найти службы по имени или отображаемому названию,
выбрать нужные и нажать «Применить». Выбранные службы отображаются в основном
окне и доступны в контекстном меню трея. Набор сохраняется между запусками
приложения.

## Сборка и запуск

```
cd C:\Users\Vladimir\service_manager
flutter pub get
flutter build windows --release
```

Готовый exe: `build\windows\x64\runner\Release\service_manager.exe`

Разработка: `flutter run -d windows`

### Сборка без режима разработчика Windows

Flutter при сборке Windows создаёт симлинки плагинов, а для этого нужен
включённый **Developer Mode** или права администратора. Если сборка падает
с ошибкой «Building with plugins requires symlink support», выполните:

```
powershell -ExecutionPolicy Bypass -File .\scripts\restore_plugin_symlinks.ps1
flutter build windows --release
```

Скрипт создаёт junction'ы (каталоги-переходы) на плагины из pub-кеша вместо
симлинков — права администратора не требуются. Запускайте его заново после
`flutter pub get`, если менялся список плагинов.

## Важно

- Запуск и остановка служб требуют прав администратора. При попытке управления без прав приложение предложит перезапуститься от имени администратора.
- Список служб загружается из Windows и настраивается пользователем в окне выбора служб.

## Как это работает

Управление службами выполняется через Windows Service Control Manager API. Проверка прав администратора выполняется через Windows API.
